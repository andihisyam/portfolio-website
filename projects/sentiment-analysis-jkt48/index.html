Sentiment Analysis: JKT48 on X (Twitter)

Personal Project • NLP • Topic Insight

This project analyzes public perception of JKT48 on X (Twitter) by collecting tweets using the keyword jkt48, cleaning Indonesian text (NLTK + Sastrawi), scoring sentiment with NRC Lexicon, and summarizing the most discussed topics.

View GitHub Contact

At a glance

~1,000 tweets X (Twitter) crawling NRC Lexicon Pos / Neg / Neutral Topic summarization

Goal: Identify what fans talk about most and what the sentiment looks like for each topic.

Project Scope

The workflow covers: tweet crawling → preprocessing → NRC-based sentiment scoring → visualization → interpretation → topic mining/summarization.

Data mining is done using Tweet Harvest, adapted from the tweet-harvest repository.

Dataset

Source: X (Twitter). Query: jkt48. Size: ~1,000 tweets.

Output labels: positive, negative, and neutral.

Preprocessing

URL/mention cleanup Tokenization Stopwords Stemming (Sastrawi)

Sentiment Method

NRC Lexicon Lexicon mapping Pos/Neg/Neutral

Lexicon-based approach to score sentiment without supervised training.

Tech Stack

Python pandas NLTK Sastrawi Matplotlib/Seaborn

Key Outputs

  • Most discussed topics among JKT48 fans on X.
  • Sentiment distribution (positive/negative/neutral) overall and per topic.
  • Visual summaries and interpretation notes.

Report files and documentation are available in the repository folder.
